# מעלה סרטונים אוטומטי לטיקטוק

כלי מקומי שמעלה סרטונים לחשבון הטיקטוק שלכם לפי לוח זמנים — שמים קבצים בתיקייה,
והתוכנה מפרסמת אחד בכל חלון זמן שהגדרתם. יש לוח בקרה בדפדפן לניהול התור.

בנוי על **Content Posting API הרשמי של טיקטוק** עם OAuth. הוא לא מדמה דפדפן ולא
נוגע בממשק של tiktok.com — אוטומציה כזאת מפרה את תנאי השימוש ונשברת בכל שינוי עיצוב.

---

## מה צריך לפני שמתחילים

הכלי מפרסם דרך ה-API הרשמי, ולכן צריך אפליקציית מפתחים משלכם:

1. היכנסו ל-<https://developers.tiktok.com/> ופתחו אפליקציה.
2. הוסיפו לה את המוצר **Content Posting API**, ובתוכו הפעילו **Direct Post**.
3. בקשו את ההרשאות `user.info.basic`, `video.publish`, `video.upload`.
4. הוסיפו Redirect URI בדיוק כזה: `http://127.0.0.1:8765/auth/callback`
5. העתיקו את ה-Client Key וה-Client Secret.

> **חשוב — מגבלת ה-audit של טיקטוק.**
> כל עוד האפליקציה לא עברה בדיקה (audit) של טיקטוק, פרסום ישיר מוגבל: טיקטוק
> תאפשר לפרסם **רק כפרטי** (`SELF_ONLY`), גם אם תבקשו פומבי. זו מגבלה של טיקטוק,
> לא של הכלי. הכלי שואל את טיקטוק אילו רמות פרטיות מותרות לחשבון ונופל אוטומטית
> לרמה מותרת במקום להיכשל — ורושם על כך שורה ביומן. כדי לפרסם באמת לכולם צריך
> להגיש את האפליקציה ל-audit ולקבל אישור.

## התקנה

```bash
cd tools/tiktok-uploader
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # ואז למלא את המפתחות
```

## הפעלה

```bash
.venv/bin/python run.py
```

הדפדפן ייפתח על <http://127.0.0.1:8765>. לוחצים **חבר חשבון**, מאשרים בטיקטוק,
וחוזרים ללוח הבקרה.

## בניית סרטון מתמונות

שמים תמונות של העסק בתיקייה תחת `projects/`, ולוחצים **בנה סרטונים**. התוכנה
מייצרת סרטון 9:16 מוכן לטיקטוק: תמונות עם תנועת זום עדינה, מעברים רכים,
כיתוביות בעברית, לוגו, סיומת עם הטלפון והוואטסאפ, ומוזיקת רקע.

```
projects/shawarma-promo/
    project.json
    1.jpg
    2.jpg
    3.jpg
```

```json
{
  "kind": "menu",
  "headline": "שווארמה טרייה כל היום",
  "slides": [
    {"image": "1.jpg", "text": "שווארמה טרייה כל היום"},
    {"image": "2.jpg", "text": "פיתה, לאפה או בצלחת"}
  ],
  "hashtags": ["שווארמה"]
}
```

הכול אופציונלי. בלי `project.json` התוכנה פשוט תשתמש בכל התמונות לפי הסדר.

| שדה | משמעות |
|---|---|
| `kind` | קובע את בנק התבניות לכיתוב: `menu`, `promo`, `behind`, `place`, `general` |
| `headline` | הכותרת הראשית; מופיעה על השקופית הראשונה |
| `slides` | טקסט לכל תמונה בנפרד |
| `caption` | לדרוס לגמרי את הכיתוב האוטומטי |

התוצאה נכתבת ל-`videos/<שם-הפרויקט>.mp4` יחד עם קובץ כיתוב, ומשם היא נכנסת
לתור הפרסום הרגיל.

**הכיתובים נוצרים מתבניות** — בנק פתיחים, סגירים ואשהטגים לפי סוג הסרטון, עם
בחירה שמבוססת על שם הפרויקט כדי ששני סרטונים ברצף לא ייצאו זהים. בלי API ובלי
עלות.

### פונט ומוזיקה

- **פונט:** התוכנה מאתרת לבד פונט עם תמיכה בעברית. ברירת המחדל במערכת נראית
  בסדר אבל לא יותר מזה — כדאי להוריד את **Heebo-Bold.ttf** ולשים ב-`assets/fonts/`.
- **מוזיקה:** קבצי `.mp3` בתיקייה `assets/music/`. נבחר אחד אקראית לכל סרטון.
  **שימו לב לזכויות** — אל תשימו שם מוזיקה מיוטיוב. מוזיקה חופשית לשימוש מסחרי
  אפשר למצוא ב-Pixabay Music או ב-YouTube Audio Library.

## איך מוסיפים סרטון מוכן

אם כבר יש לכם סרטון ערוך — שמים קובץ בתיקייה `videos/` ולוחצים **סרוק תיקייה**.
נתמכים `.mp4`, `.mov`, `.webm`, `.avi`, `.mkv`.

בלי הגדרות נוספות, הכיתוב ייגזר משם הקובץ. לשליטה מלאה — הוסיפו קובץ JSON באותו
שם ליד הסרטון:

```
videos/promo.mp4
videos/promo.json
```

```json
{
  "title": "שווארמה טרייה כל היום #שווארמה #באר_שבע",
  "privacy_level": "PUBLIC_TO_EVERYONE",
  "publish_at": "2026-08-20T18:00:00+03:00",
  "disable_comment": false,
  "disable_duet": false,
  "disable_stitch": false,
  "cover_timestamp_ms": 1500
}
```

כל השדות אופציונליים:

| שדה | משמעות |
|---|---|
| `title` | הכיתוב, כולל האשטגים. עד 2200 תווים. |
| `privacy_level` | `PUBLIC_TO_EVERYONE` / `MUTUAL_FOLLOW_FRIENDS` / `FOLLOWER_OF_CREATOR` / `SELF_ONLY` |
| `publish_at` | זמן פרסום מדויק (ISO 8601). גובר על שעות לוח הזמנים. |
| `cover_timestamp_ms` | מאיזו נקודה בסרטון לקחת תמונת שער. |

**זיהוי לפי תוכן:** כל סרטון מזוהה לפי hash של הקובץ, כך ששינוי שם, העברה או
סריקה חוזרת לא יגרמו לפרסום כפול.

## לוח הזמנים

ב-`.env`:

```ini
SCHEDULE_TIMES=10:00,18:00   # שעות מקומיות; סרטון אחד בכל חלון
MIN_GAP_MINUTES=30           # מרווח מינימלי בין פרסומים
AUTOPOST=true                # אפשר לכבות זמנית מלוח הבקרה
MAX_ATTEMPTS=3               # כמה ניסיונות לפני סימון ככישלון
```

בכל חלון זמן מתפרסם הסרטון הוותיק ביותר שממתין. סרטון עם `publish_at` מתפרסם
בזמן שלו בלי קשר לחלונות. אפשר תמיד ללחוץ **פרסם עכשיו** על שורה בתור.

להרצה קבועה ברקע אפשר להוסיף ל-crontab או ל-systemd — הכלי מיועד לרוץ ברציפות.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `run.py` | נקודת כניסה: מרים את המתזמן ואת לוח הבקרה |
| `tiktok_uploader/config.py` | טעינת הגדרות מ-`.env` |
| `tiktok_uploader/auth.py` | OAuth 2.0 עם PKCE, שמירה ורענון טוקנים |
| `tiktok_uploader/api.py` | לקוח ה-API: creator_info, init, העלאה בנתחים, מעקב סטטוס |
| `tiktok_uploader/scanner.py` | סריקת התיקייה, קריאת ה-sidecar, hashing |
| `tiktok_uploader/videobuild.py` | בניית הסליידשו: Pillow מרכיב, ffmpeg מניע |
| `tiktok_uploader/textrender.py` | טקסט עברי (bidi), גלישת שורות, חיתוך תמונות |
| `tiktok_uploader/captions.py` | תבניות כיתוב ואשהטגים |
| `tiktok_uploader/projects.py` | פרויקט → סרטון + קובץ כיתוב |
| `tiktok_uploader/poster.py` | תהליך הפרסום המלא + לולאת התזמון |
| `tiktok_uploader/dashboard.py` | שרת Flask ו-API של לוח הבקרה |
| `tests/test_flow.py` | בדיקות מקצה לקצה מול שרת טיקטוק מדומה |
| `tests/test_video.py` | בדיקות של בניית הווידאו והכיתובים |

## בדיקות

```bash
.venv/bin/python -m tests.test_flow    # פרסום
.venv/bin/python -m tests.test_video   # בניית וידאו
```

הבדיקות מרימות שרת HTTP מקומי שמדבר את הפרוטוקול של טיקטוק ומריצות דרכו את
הלקוח האמיתי: `creator_info` → `init` → העלאה בנתחים → polling. הן מוודאות בין
היתר שהבייטים מגיעים שלמים אחרי הפירוק לנתחים, שהכיתוב עובר נכון, ושנעילות
שטיקטוק מחזירה (למשל stitch חסום) מכובדות.

בדיקות הווידאו מרנדרות סרטון אמיתי ובודקות את התוצאה: 1080x1920, `yuv420p`
(פורמט שנגן בנייד מקבל — 4:4:4 נדחה בהרבה מכשירים), 30fps, פסקול, ושהעברית
לא יוצאת הפוכה.

## אבטחה

- לוח הבקרה מאזין על `127.0.0.1` בלבד. הוא מחזיק טוקן גישה פעיל — **אל תחשפו
  אותו לרשת** בלי להוסיף אימות אמיתי לפניו.
- `.env`, `state/` (הטוקנים ומסד הנתונים) ותוכן `videos/` כולם ב-`.gitignore`.
- קובץ הטוקנים נכתב בהרשאות `600`.

## מגבלות שכדאי להכיר

- **לא נבדק מול טיקטוק אמיתי.** נכתב ונבדק בסביבה בלי גישה לרשת של טיקטוק ובלי
  חשבון מפתחים, ולכן כל האימות נעשה מול שרת מדומה. ההעלאה האמיתית הראשונה היא
  שלכם — מומלץ להתחיל בסרטון קצר עם `"privacy_level": "SELF_ONLY"`.
- טיקטוק מגבילה כמות פרסומים בפרק זמן. `MIN_GAP_MINUTES` נועד לשמור מרווח שפוי.
- בניית הווידאו נבדקה מול תמונות שנוצרו לצורך הבדיקה, לא מול צילומים אמיתיים
  של העסק. כדאי לבנות פרויקט אחד ולראות את התוצאה לפני שמפעילים תזמון אוטומטי.
- אין זיהוי דיבור ואין תמלול — הכיתוביות הן הטקסט שאתם כותבים ב-`project.json`.
