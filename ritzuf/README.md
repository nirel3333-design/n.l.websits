# מחשבון פריסת ריצוף

אפליקציית ווב בקובץ HTML יחיד (בלי פריימוורקים, בלי תלויות), בעברית עם RTL מלא, מותאמת לעבודה בנייד בשטח.

פתיחה: `ritzuf/index.html` — אפשר לפתוח ישירות מהדפדפן או להעלות לשרת (`/ritzuf/`).

## מה היא עושה

**קלט**
- מידות החדר בס״מ + ניכויים (עמוד / ארון / נישה) לפי מיקום ומידה
- מידת האריח (כולל גדלים נפוצים והיפוך אריח) ורוחב פוגה במ״מ
- דגם פריסה: ישר (רשת), חצי אריח (בריק), שליש אריח, אלכסון 45°
- נקודת התחלה: ממרכז החדר או מפינה, עם הזזה ידנית בכל ציר
- כמה אריחים בחבילה ואחוז פחת
- העלאת תמונת אריח — משמשת כטקסטורה בהדמיה

**פלט**
- כמות: אריחים שלמים, חתוכים, סה״כ כולל פחת, וכמה חבילות לקנות (מעוגל למעלה)
- רשימת חיתוכים: מידה מדויקת בס״מ, כמות יחידות מכל חיתוך, באיזה קיר, ואיזו צורה
- הדמיה דו־ממדית מלמעלה על Canvas עם הטקסטורה, הפוגות, וחיתוכים מסומנים באדום עם המידה עליהם (זום/הזזה במגע)
- בדיקת קירות + התראות מקצועיות
- ייצוא PDF (דרך חלון ההדפסה של הדפדפן) ושיתוף התמונה והסיכום בוואטסאפ

## כללי המקצוע שמוטמעים בלוגיקה

1. **אין חיתוך צר מ־⅓ אריח בקצוות.** אם החישוב נותן חיתוך צר מדי, נקודת ההתחלה מוזזת כדי לאזן את החיתוכים בשני הצדדים, ומוצגת ההודעה "מומלץ להזיז את ההתחלה ב־X ס״מ". האיזון מתחשב גם בשורות המוזזות של בריק/שליש — לא רק בשורה הבסיסית. אפשר לכבות את הכלל בתיבת "איזון אוטומטי", ואז מוצגת אזהרה בלבד.
2. **פריסה ממרכז החדר** מבטיחה חיתוכים שווים בשני הקירות הנגדיים, והדבר נבדק ומדווח בפועל מתוך הפריסה שחושבה.
3. **הפוגה נספרת בין כל שני אריחים ולא בקצה הקיר**: חיתוך הקצה = (שארית / 2) − פוגה.

## חישוב

השטח מפורק למלבנים זרים (חדר פחות ניכויים), כל אריח נחתך גאומטרית מול המלבנים האלה (Sutherland–Hodgman), וכל חתיכה מסווגת כשלמה או כחיתוך לפי השטח שנשאר. באלכסון הרשת מסובבת ב־45° והחיתוכים מדווחים לפי המלבן החוסם של החתיכה.

כל חיתוך נספר כאריח נפרד — חישוב זהיר. ניצול שאריות בקצה השני יקטין את הכמות בפועל.

## בדיקות

```bash
node ritzuf/test/engine.test.js
```

הבדיקות טוענות את בלוק המנוע (`<script id="engine">`) ישירות מקובץ ה־HTML ומריצות אותו ב־Node, כך שהאפליקציה נשארת קובץ יחיד.
